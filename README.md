This is a [Next.js](https://nextjs.org/) project using the **App Router** (`/app`) and React.

## Getting Started

Run the development server:

```bash
yarn dev
```

Open http://localhost:3000 in your browser.

Start editing the homepage in `app/page.js` (layout is in `app/layout.js`).

## Scripts

- `yarn dev` — dev server
- `yarn build` — production build
- `yarn start` — run the production server
- `yarn lint` — run Next.js lint
